# 🐾 Dispenser Automático de Ração

## 📌 Visão Geral

O **Dispenser Automático de Ração** é um projeto de automação residencial desenvolvido para alimentar pets de forma programada e remota. Com estrutura impressa em 3D e capacidade para até 2 kg de ração, o dispositivo é ideal para quem busca praticidade e cuidado com seus animais de estimação.

## 🛠️ Funcionalidades

- ✅ Controle remoto via aplicativo Blynk usando ESP12  
- ✅ Motor com eixo rosqueado para liberar ração com precisão  
- ✅ Alerta sonoro com buzzer passivo  
- ✅ Estrutura impressa em 3D com capacidade para até 2 kg  
- ✅ Códigos para PIC, Arduino e ESP12 disponíveis  

## 🎓 Contexto Acadêmico

Este projeto foi desenvolvido como trabalho final para as disciplinas de **Sistemas Embarcados** e **Técnicas Avançadas em Microcontroladores** no curso de Engenharia da Computação. Também foi apresentado em eventos como a **Semana da Engenharia** e a **ExpoIOT**.

## 🚀 Como Usar

1. Clone este repositório:
   ```bash
   git clone https://github.com/gilsonfiho/Dispenser_Automatico_Racao.git
   ```

2. Escolha a versão desejada (PIC ou ESP12).

3. Monte o circuito físico conforme descrito na documentação.

4. Compile e envie o código utilizando a IDE apropriada:
   - MPLAB X para PIC  
   - Arduino IDE ou PlatformIO para ESP12  

5. Configure o aplicativo **Blynk** com os widgets adequados para ativar o dispenser remotamente.

6. Alimente seu pet com estilo! 🐶🐱

7. Atualizações estão por vir.
